- `hawk-mason-mark.png` — işaret (papağan), dikey; sitede `assets/hawk-mason-mark.{png,webp}` ile aynı.

- `hawk-mason-lockup-vertical.png` / `-horizontal.png` — işaret + yazı kilidi (basın, partner, mağaza).
- `hawk-mason-icon-512.png` — krem yuvarlak kare üzerinde işaret (favicon/ikon kaynağı).
